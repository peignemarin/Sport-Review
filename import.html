Import

Importer une activité

Dépose l'export Garmin (.zip) d'une course, puis renseigne son nom et son temps officiels.

L'import ne fonctionne qu'en local. Dans VS Code, ouvre le terminal (Ctrl+`), tape python3 server.py puis ouvre http://localhost:8000/import.html.

Nouvel import

h:mm:ss ou mm:ss

Imports enregistrés

Les fichiers .zip restent sur ton ordinateur (data/raw/, non publié). Seuls les chiffres sont enregistrés dans data/imports.json.
